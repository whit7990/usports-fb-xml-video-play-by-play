# usports-fb-xml-video-play-by-play

This Colab takes a Stat Crew/Presto XML file and extracts the play-by-play information for video review into a .csv file.

## Usage

1. You should be logged in with a Google specific account (ie gmail)
1. View the XML-Football-Video-Play-By-Play.ipynb in Github and it will have a link to Open in Colab in the upper left
1. Click Connect in the upper right once the Colab is opened.
1. Click Run All in the top bar
     - You may be prompted with a warning that the Colab will have access to your Google resources. Click Run Anways. The Colab only accesses the XML file.
1. You will be promoted to upload a .xml file to extract the play-by-plays from.
